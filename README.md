# Kiln website

Static GitHub Pages site for [Kiln GNU/Linux](https://kiln.mandrusia.tech).

Original Kiln logos and favicon are copied unmodified from `hexsourceorg/kiln-gnu-linux` (the `beta` branch). The screenshots were supplied by the project creator and show Kiln/Glaze in QEMU. The site uses no external libraries.

The website does not host an ISO. It links to the project's build instructions because the source README identifies Kiln as an early beta, with x86_64 hardware testing not yet complete.

Keep the `CNAME` file in the site repository to retain the custom domain.

Maintained by **[Hexsource](https://hexsource.mandrusia.tech/)**. Kiln retains its independent logo and visual identity.
